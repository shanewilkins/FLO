# Design ADRs

Status: accepted

This directory holds architecture decision records for FLO.

Each ADR should capture:

- context
- decision
- consequences

ADRs use one controlled status near the top:

- `Status: proposed`
- `Status: accepted`
- `Status: superseded`

Accepted ADRs are not rewritten to make a later direction appear original. A
new ADR supersedes the old one and links back to it.

ADRs are explanatory decision records.
Normative behavior still belongs in `docs/specs/` and governance rules belong in
`docs/policy/`.
